# Job Recommendation Using Skill-Job Bipartite Graphs

A Graph Mining case study that models job postings and their required skills as a **bipartite graph**, then uses graph-based link prediction to recommend jobs to a candidate based on their skill set.

## Problem Statement

Given a candidate's skills, recommend the most relevant jobs by representing skills and jobs as two node sets in a bipartite graph, connected by edges where a job requires a skill. Recommendations are generated by scoring how "close" a candidate (represented as a graph node) is to each job node, using graph mining techniques rather than traditional keyword matching.

## Approach

1. **Model** skills and jobs as a weighted, undirected bipartite graph — edge weight is based on inverse skill frequency, so rarer/more specialized skills carry more signal than common ones.
2. **Represent** a candidate as a temporary node connected to their own skills.
3. **Score** every job node's relevance to the candidate using **Personalized PageRank (Random Walk with Restart)**, which naturally favors jobs reachable through rare, high-signal shared skills.
4. **Rank and recommend** the top-N scoring jobs, with visualizations and result analysis.

## Dataset

[Data Science Job Postings & Skills (2024)](https://www.kaggle.com/datasets/asaniczka/data-science-job-postings-and-skills) — Kaggle, via `job_postings.csv` (job details) joined with `job_skills.csv` (required skills per posting) on `job_link`.

Final graph used: **30 job nodes, 50 skill nodes, 245 weighted edges**, after cleaning skill text against a curated whitelist of real technical/professional skills (the raw `job_skills` field contained a lot of non-skill text like benefits and degree requirements, which was filtered out).
